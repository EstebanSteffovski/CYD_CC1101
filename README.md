# Снифер шлагбаума: CYD + CC1101 (прототип)

**Прошивка:** v1.0.0
**Плата:** ESP32-2432S028R (CYD, Cheap Yellow Display)
**Радиомодуль:** CC1101 433 МГц

## Что делает

Три кнопки на экране (кириллица):

1. **Снифер** — переход в режим захвата: прослушивание 433 МГц. Нажми кнопку пульта шлагбаума — устройство поймает сырые импульсы (OOK-демодуляция через GDO0 → RMT-таймер ESP32), покажет количество импульсов, RSSI и мини-осциллограмму.
2. **Записать** — сохранить последний захват в энергонезависимую память (NVS): частота, модуляция, длительности импульсов.
3. **Воспроизвести** — переиграть сохранённый сигнал: ESP32 через RMT подаёт импульсы на GDO0, CC1101 в async-TX модулирует ими несущую.

## Подключение CC1101 к CYD

На CYD всего два SPI (HSPI — дисплей, VSPI — тач). CC1101 разделяет шину VSPI с тачем (это штатное решение для CYD — шина общая, устройства различаются по CS):

| CC1101 | CYD GPIO | Откуда |
|--------|----------|--------|
| VCC    | 3.3V     | любой разъём |
| GND    | GND      | P3 или CN1 |
| SCK    | **GPIO 25** | пайка к пину тача CLK (или дорезать дорожку) |
| MISO   | **GPIO 39** | пайка к пину тача MISO |
| MOSI   | **GPIO 32** | пайка к пину тача MOSI |
| CSN    | **GPIO 22** | разъём P3 (или CN1) |
| GDO0   | **GPIO 27** | разъём CN1 |

GDO2 не подключается.

**Пайка к пинам тача:** свободные выводы SCK/MOSI/MISO тача XPT2046 (25/32/39) — удобно взять с ножек резисторов последовательной защиты или с самой колодки тача.

**Альтернатива без пайки к тачу:** если найдётся свободный SPI-мост — на CYD больше нет второго свободного SPI, это единственный вариант.

## Экраны

### Меню
- Заголовок «СНИФЕР ШЛАГБАУМА», частота внизу.
- 3 кнопки: Снифер (голубая), Записать (зелёная), Воспроизвести (оранжевая).

### Режим снифера
- «Нажми кнопку пульта», таймер ожидания, мигающий индикатор, кнопка «Стоп / Меню».
- Слушает до 5 с (правится в `config.h` — `CAPTURE_TIMEOUT_MS`).
- Пойманный сигнал → экран результата.

### Результат
- «СИГНАЛ ПОЙМАН» (частота / импульсы / RSSI) или «НИЧЕГО НЕ ПОЙМАНО».
- Мини-осциллограмма первых импульсов.
- Кнопки: Запись / Воспр. / Меню. После записи — «СОХРАНЕНО», после повтора — «ОТПРАВЛЕНО».

## Архитектура кода

| Файл | Назначение |
|------|------------|
| `src/config.h` | Пины, частота, параметры захвата, ключи NVS |

## Ключевые технические решения

- **Async OOK снифер:** CC1101 настроен в прозрачный режим (`PKTCTRL0=0x32`, `IOCFG0=0x0D`) — GDO0 выдаёт демодулированный битовый поток. ESP32 читает его аппаратно через **RMT в RX-режиме** (1 МГц = 1 тик/мкс) — точность захвата ±1 мкс, без загрузки CPU.
- **Воспроизведение:** обратная схема — RMT в TX-режиме гонит импульсы на GDO0, CC1101 в async-TX модулирует ими несущую.
- **Скорость радио:** 10 кБод, полоса 270 кГц — покрывает большинство статических кодов шлагбаумов (CAME, NICE, DoorHan и подобных — от 0.6 до 20 кБод).
- **Кириллица:** `U8g2_for_TFT_eSPI` со шрифтами `u8g2_font_10x20_t_cyrillic` и `u8g2_font_6x12_t_cyrillic`.

## Настройка частоты

По умолчанию 433.92 МГц (константа `BARRIER_FREQ_MHZ` в `src/config.h`).
Если твой барьер на 433.42/868.3 и т.п. — поменяй и перекомпилируй (в следующей версии — правка на экране).

## Ограничения прототипа

- Захват и воспроизведение только OOK/ASK (2-GFSK пульты не подойдут без доработки).
- Динамический код (rolling code, например CAME BPT, FAAC SLH) — записывается, но повтор не сработает: код одноразовый. Это нормально: для них нужен алгоритм декодирования.
- Только один слот памяти (перезаписывается при каждой записи).

## Планы (v2)

- Несколько слотов памяти + имена сигналов.
- Сканер частот (быстрый перебор популярных каналов с RSSI-индикацией).
